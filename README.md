# 麻雀点数計算クイズ

麻雀の役・符・点数計算を4択クイズ形式で学べるWebアプリです。React + TypeScript + Viteで実装しています。

手牌と状況（親/子、ロン/ツモ、リーチなど）が提示されるので、和了時の点数を4択から選びます。回答すると正解/不正解と、成立した役・符計算の内訳・最終点数までの全過程が表示されます。

## 使い方

```bash
npm install
npm run dev      # 開発サーバーを起動
npm run test     # 採点エンジンの単体テストを実行
npm run build    # 型チェック + 本番ビルド
```

## 構成

- `src/domain/` — 役判定に依存しない純粋な採点ロジック（翻数・符計算・点数表・4択の誤答生成）
- `src/data/questions/` — 型付きで手作りした約18問の問題データ
- `src/components/`, `src/pages/`, `src/hooks/` — クイズ画面のUI
- `tests/` — 採点エンジンおよび問題データの検証テスト（Vitest）

## 対応範囲

基本〜頻出の役（約20種）と符計算・翻符点数表をカバーしています。役満・数え役満は対象外です。
